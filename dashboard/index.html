How the value is worked out

Size curve. The 128 protocols in this snapshot whose token already trades are the comparables. A line is fitted through them in log space — log10(market cap) on log10(TVL) — and a pre-token protocol's curve value is read off that line at its own TVL. Big protocols carry a smaller multiple than small ones: the curve is concave, and the fit says so.

Growth and maturity. The curve value is multiplied by a growth factor from the protocol's seven-day TVL change (clamped to −50%…+100%, half weight) and a maturity factor from how long DefiLlama has tracked it with no token (0.80 for a newcomer, up to 1.00 after three years). No protocol's name ever matters: the same three numbers score every row.

What this radar does not claim. The snapshot carries no launch history, so no launch date is ever predicted and no protocol is said to have no token — only that its DefiLlama record carries none. The implied value is the entry's own claim: what a token would be worth if the protocol's record stayed as it is.

How the curve was tested

Four out-of-sample tests plus a 1000-round bootstrap, each against the same flat baseline (predict every comp at the median market-cap/TVL multiple). Coverage audit

Farm plans, netted to the dollar

Every plan costs its gas on the cheapest chain the protocol itself lists, at the model's estimated per-transaction fee (7 transactions: 2 to set up, 4 weekly actions, 1 to claim). The gas fees are estimates, stated as such; the capital stays the reader's and is withdrawable, so only the gas is spent. Each plan closes with one net line: gas total + capital locked + time. Each step says why the action counts — a deposit, a stake or a vote is only worth doing if the snapshot can see it.
